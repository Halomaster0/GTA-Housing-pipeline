# Standups

One file per work session, written by `chief-of-staff` at session close, named `YYYY-MM-DD.md`.

Fixed format: Shipped (with file paths) · In flight · Blocked (with owner and any CEO decision needed) · Numbers (real values only, or an explicit "not yet measured") · Next session.

These stay in the repository on purpose. Showing the process is part of the point.
